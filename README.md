# StockManager

A full-stack stock management application.

## Project Overview

StockManager is a learning project designed to simulate
a real-world inventory management system.

## Technology Stack

### Backend
- Java 21
- Spring Boot
- Maven
- PostgreSQL

### Frontend
- React
- TypeScript
- HTML
- CSS

### Testing and Tools
- JUnit
- Mockito
- Git
- Docker

## Planned Features

- Product management (CRUD)
- Inventory management
- Stock level monitoring
- REST API
- User authentication and authorization
- Automated tests

## Project Status

Currently in development.
